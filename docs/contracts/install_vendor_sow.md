# Install Vendor Statement of Work (summary of key terms)

Applies to: Apex Field Tech, NorthStar Install and FieldPro Services. Sample contract for practice use.

## Section 2.1 Scope

The vendor installs the router and switch, connects the circuit, runs the turn-up test with the
network operations center, and photographs the finished network closet.

## Section 3.1 Scheduling

The vendor confirms each technician visit at least 5 business days ahead and calls the site
contact 24 hours before arrival.

## Section 3.4 Aborted visits and who pays

An aborted visit is a technician visit that ends without a working install.
- If the cause is on the customer side (site not ready, no access, circuit not active, no power),
  the customer pays an **abort fee of $350**.
- If the cause is on the vendor side (technician no-show, wrong hardware brought, incomplete
  work), the vendor pays for the return visit and credits **$200** to the customer.

## Section 5.1 Quality target

The vendor will achieve **95% first-time install success** (installs finished on the first visit),
measured each month. Two months in a row below 90% allows the customer to move sites to another vendor.

## Section 7.2 Reporting

The vendor sends a weekly report each Friday listing visits completed, aborted, and planned.
