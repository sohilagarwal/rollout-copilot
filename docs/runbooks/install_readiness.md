# Install Readiness Runbook

A site is ready to install only when all five checks below are true.
Run the checklist 10 days and again 3 days before each technician visit.

## Check 1 Circuit delivered

The carrier has delivered and tested the circuit. If not delivered 5 days before the visit,
move the visit. Sending a technician to a site with no circuit causes a $350 abort fee.

## Check 2 Hardware on site

Router and switch are delivered to the site, or with the technician. Backordered hardware with an
arrival date after the visit means the visit must move.

## Check 3 Site ready

The store confirmed access, power in the network closet, and a contact on the day.
"Not confirmed" 10 days out means call the store manager.

## Check 4 Technician confirmed

The install vendor confirmed a named technician and time, at least 5 business days ahead.

## Check 5 Turn-up slot booked

A slot is booked with the network operations center for the turn-up test.

## Moving a visit

Moving a visit at least 2 business days ahead costs nothing. Inside 2 business days, treat it as
an aborted visit under the install vendor statement of work, section 3.4.
